Gradient Calculation Method

梯度的计算

1、概念：

梯度是多变量函数在某点的变化率方向，指向函数值增加最快的方向。

2、一维梯度

导数是梯度的基础，在一维函数（比如 y = f(x)）中，它表示函数在某点的变化率。简单说，就是“斜率”。

3、多维梯度

现实世界不是一维的。在机器学习中，函数往往是多变量的，像 z = f(x, y)，这时候导数就不够用了。需要“梯度”——一个向量（箭头），它指向函数增长最快的方向，并告诉你增长的速度。 定义：梯度（Gradient）是一个向量，由函数对每个变量的偏导数组成。 对于函数 f(x, y)，梯度是： ∇f=（∂f/∂x,∂f/∂y） 梯度的方向：指向函数值增加最快的方向（上坡）。梯度的长度（模）：表示变化的陡峭程度。比如高度是 f(x, y)，x 和 y 是经纬度。梯度向量像 GPS 箭头，告诉你“往这个方向走，能最快爬上山顶”。

4、计算梯度

比如曲线函数： f(x, y) = x² + y²，最低点在 (0,0)。 偏导数对 x： ∂f/∂x = 2x 偏导数对 y： ∂f/∂y = 2y 所以，梯度 ∇f = (2x, 2y) 梯度向量的模=√( 〖(∂f/∂x) 〗^2+〖(∂f/∂y) 〗^2 )

5、梯度函数

在 Python 中，NumPy 库提供了一个非常有用的函数 np.gradient，用于计算数组中元素的梯度。梯度是一个向量（或者在一维情况下是一个数值），指示函数在每个点上最陡峭的上升方向。在多维数组中，梯度的计算会针对每个维度进行。 梯度计算是通过分析函数在各个方向上的变化率来完成的。在一维数组中，梯度简单地表示为相邻点之间的差异。在多维数组中，梯度则是每个维度上的变化率的集合。例如，对于二维数组，梯度将包含两个数组，分别代表行和列方向上的变化率。 np.gradient 函数接受以下参数：
f：输入数组，可以是任意维度的 NumPy 数组。
varargs：可选参数，用于指定沿各个维度的间距。如果未指定，NumPy 默认所有维度的间距为1。
edge_order：可选参数，用于指定边界点的梯度计算方法。可以是1或2，其中1表示使用一阶差分，2表示使用二阶差分。
axis：可选参数，用于指定需要计算梯度的轴。默认情况下，梯度将针对所有轴计算。
函数返回的是一个数组或数组列表，这取决于输入数组的维度。每个数组代表对应维度上的梯度。
